# Titulo & descrição curta: 
Calculo de média

## Tecnologia Utilizada: 
python2026.3.1

## Como instalar e executar: 
Abra o vscode e baixe a extenção do python ou execute no site [CalculoMedia](https://www.mycompiler.io/pt/new/python) .No terminal do vscode, voçê executa o codigo num arquivo python, preenchendo os valores pedido.

## Exemplo de uso ou demonstração: 
Depois de inserir os valoresno terminal, ele vai calcular a sua média. Se sua média for menor que 7, vai aparecer uma mensagem dizendo "Você esta reprovado sua nota foi apenas(media)". Se o valor for maior que 7 , vai aparecer "Você está aprovado, sua media foi(media)".
